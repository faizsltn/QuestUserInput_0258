# User Input Android App

Aplikasi sederhana berbasis Android menggunakan **Kotlin** dan **Jetpack Compose** untuk mengumpulkan data diri pengguna (Nama Lengkap, Jenis Kelamin, dan Alamat) serta menampilkannya kembali ke dalam komponen kartu (*ElevatedCard*) setelah tombol submit ditekan.

---

## 📱 Fitur Aplikasi
- **Input Nama Lengkap**: Menggunakan `OutlinedTextField`.
- **Pilihan Jenis Kelamin**: Menggunakan komponen `RadioButton` secara dinamis.
- **Input Alamat**: Menggunakan `OutlinedTextField`.
- **Tombol Submit**: Tombol validasi yang akan aktif jika semua kolom terisi.
- **Card Hasil**: Menampilkan ringkasan data yang telah diinput dengan latar belakang khusus.
